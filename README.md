# MineTunnelLoc

Project repository for **Multi-layer orthogonal-view representation for LiDAR place recognition in underground mining tunnels**.

MineTunnelLoc uses a multi-layer orthogonal-view representation, adaptive dual-view layer-wise fusion for global retrieval, and cross-section sequence matching for candidate reranking.

The source code will be released after publication of the paper.
